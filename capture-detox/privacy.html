개인정보처리방침

캡처 디톡스 (Android 앱) · 시행일 2026년 10월 22일

요약

캡처 디톡스는 회원가입, 광고, 분석 도구가 없습니다. 캡처 이미지와 캡처에서 읽은 글자는 기기 안에서만 처리되며 개발자를 포함한 누구에게도 전송되지 않습니다. 다만 글자 인식에 쓰는 Google ML Kit가 기능 진단을 위해 기기·앱 정보와 성능 지표를 Google에 보냅니다(4항).

1. 앱이 사용하는 권한

권한목적
사진 및 동영상(모두 허용 또는 선택한 사진)스크린샷 폴더의 캡처를 찾아 썸네일을 만들고 글자를 읽어, 지울 캡처와 살릴 캡처(기프티콘, 예약, 고지서 등)를 나눕니다.
미디어 관리(선택)켜면 캡처를 휴지통으로 옮길 때 안드로이드 확인 창을 띄우지 않습니다.
알림(선택)살린 캡처의 만료일·일정 알림과 새 캡처 알림을 보냅니다.
부팅 완료 수신기기를 다시 켰을 때 예약한 알림을 다시 겁니다.

2. 기기 안에 저장되는 정보

항목목적보관
캡처별 읽은 글자와 분류 결과, 작은 썸네일다시 읽지 않고 바로 보여 주기앱 삭제 또는 앱 데이터 삭제 시 함께 삭제
살린 캡처의 내용(상품명, 날짜, 금액, 계좌 등 캡처에서 읽은 것)과 알림 예약알림 보내기, 살린 것 목록
정리 기록, 오늘 무료 삭제 수, 알림 시각 등 설정기록 보기, 설정 유지

이 정보는 앱의 로컬 저장소에만 있으며 서버로 보내지 않습니다.

3. 캡처 지우기

앱은 이용자가 지우기를 누른 캡처만, 안드로이드 확인 창(또는 이용자가 켠 미디어 관리 권한)을 거쳐 기기의 휴지통으로 옮깁니다. 휴지통의 캡처는 30일 동안 되살릴 수 있고, 그 뒤 안드로이드가 영구 삭제합니다.

4. Google ML Kit(글자 인식)

글자 인식은 Google Play 서비스로 내려받는 한국어 모델로 기기 안에서 이루어지며, 캡처 이미지와 읽은 글자는 전송되지 않습니다. ML Kit는 진단과 사용 분석을 위해 다음 정보를 HTTPS로 Google에 보냅니다.

  • 기기 정보(제조사, 모델, OS 버전·빌드, 사용 가능한 하드웨어 가속기)
  • 앱 정보(패키지 이름, 앱 버전)
  • 설치별 식별자(이용자나 기기를 식별하려는 것이 아닌 값)
  • 성능 지표(처리 시간 등), API 설정, 입력·결과 크기, 기능 버전, 이벤트 종류, 오류 코드

자세한 내용은 ML Kit 데이터 공개 안내를 따릅니다.

5. 제3자 제공

개인정보를 제3자에게 판매하거나 제공하지 않습니다.

6. 아동의 개인정보

이 앱은 만 13세 미만 아동을 대상으로 하지 않습니다. 앱은 이름, 이메일, 전화번호, 위치, 광고 ID 같은 개인정보를 받지 않습니다.

7. 방침 변경

광고나 분석 기능을 추가하는 등 처리 내용이 바뀌면 이 페이지를 수정하고 시행일을 갱신합니다.
