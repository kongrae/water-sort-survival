# 보트리스 폰트·모션·사운드 점검

2026-10-09, 로컬 구현과 검증을 완료했다. 최종 전수 검사 **2,741/2,741**, 실패 0건이다. 검사 전 소스를 보존하고 동일한 383조건을 비교했다. 수정 전 211조건이 실패했고, 수정 후 같은 383조건은 모두 통과했다. 같은 결함을 여러 언어·스킨·화면에서 재현한 수치이며, 독립적인 버그 211개를 의미하지 않는다.

## 확인한 원인과 수정

| 영역 | 재현한 문제 | 적용한 수정 |
|---|---|---|
| 게임 점수 | 고정 크기의 큰 숫자가 최고 기록 영역과 겹친다. 힌디어의 숫자 구분 방식에서는 더 작은 값도 폭이 부족하다. | 실제 텍스트 폭에 맞춰 글자 크기를 조정한다. 기존 줄 높이를 유지하고 숫자 펄스의 여유를 둔다. |
| 결과 점수 | 카운트업 시작 시 맞췄던 글자 크기로 마지막 큰 숫자를 표시해 가로로 넘친다. | 결과 표시와 매 카운트업 단계, 화면 크기 및 폰트 로딩 완료 후 크기를 다시 맞춘다. |
| 소리 종료 | 음소거, 효과 정리, 화면 숨김 뒤에도 이미 예약한 심장박동 등이 남는다. | 재생 소스를 추적하고 중단·연결 해제를 처리한다. 자연 종료한 소스도 연결을 정리한다. |
| 오디오 상태 | 닫힌 AudioContext를 계속 사용한다. 재개 Promise 실패도 처리하지 않는다. | 닫힌 컨텍스트와 출력을 다시 만들고 suspended/interrupted 재개 실패를 처리한다. 첫 사용자 활성화 뒤 초기화하며 터치 종료·클릭·키보드에도 대응한다. |
| 소리 중첩 | 기본 효과는 출력 압축을 우회하고, 강화 효과도 강한 중첩 시험에서 피크가 1을 넘는다. | 두 효과 설정에 공통 출력 압축과 0.75 출력 게인을 적용한다. |
| 안내 모션 | CSS의 효과 줄이기가 직접 실행한 Web Animations API 안내에는 적용되지 않는다. | 조각 이동과 붓기 안내에 같은 설정을 적용한다. 안내 표시는 남기고 움직임을 줄인다. 설정 변경은 이미 진행 중인 효과도 정리한다. |
| 게임오버 연출 | 별도 타이머와 고스트가 효과 정리에서 빠져 있다. 이전 판의 지연 콜백이 새 판의 병에 dead 상태를 적용한다. | 연출 종료 함수를 공통 정리에 연결한다. 시작한 판의 객체를 확인해 새 판에 이전 결과를 적용하지 않는다. |

기존 폰트 구성과 9개 언어를 유지했다. 신규 라이브러리·폰트 파일을 추가하지 않았다. 병 크기와 게임 규칙·저장 형식·기록 키도 유지했다. 최종 효과 검사의 390×844 lab 유리 높이는 136 CSS px다.

오디오 재개 이벤트 선택은 [Chrome의 Web Audio 안내](https://developer.chrome.com/blog/web-audio-autoplay/)도 참고했다. 첫 터치 검사는 소리가 없는 조각 선택 대신 실제 뒤집기를 실행한다. 실제 AudioContext가 running이며 재생 시계가 진행하는지 확인하고, 장치 초기화에는 최대 5초를 허용한다. 헤드리스 장치 초기화 시간을 휴대폰의 체감 반응 속도로 해석하지 않는다.

## 표시 검사 범위

`uitest/presentation-audit.js`는 정상 Pages 빌드에 격리용 저장과 관찰 훅을 넣은 테스트 문서를 사용한다. Firebase는 해당 테스트 문서에서 비활성화한다. 제품 빌드에 관찰 훅을 넣지 않는다.

- 한국어, 영어, 일본어, 중국어 간체·번체, 스페인어, 브라질 포르투갈어, 힌디어, 인도네시아어.
- 360×640, 390×844, 412×915, 768×1024, 360×600(위/아래 여백 24/24), 390×724(47/34). 안전 여백은 CSS env 대체 조건이다.
- 어두운/밝은 테마, lab/cafe/gem/deep 스킨, 6/7/8병, 123,456점/1,234,567,890점: **2,592조건**. 실제 적용한 테마·스킨·병 개수도 검사한다.
- 언어별 규칙·설정·스킨·결과·v2·조작 안내와 결과 연출 종료: **63조건**. 결과에는 123,456,789,012점을 넣어 긴 숫자를 검사한다.
- 언어별 콤보 문구 **9조건**, 폰트 서버 차단 및 경고 문구 **9조건**.
- 헤더, 점수, 병의 빈칸 문구, 트레이, 주요 버튼, 선택 상자, 결과 통계를 측정한다. 가로 넘침·점수와 기록 겹침·화면 밖 요소·터치 버튼 높이·하단 잘림을 검사한다.
- Chrome에서 실제 사용한 폰트를 기록한다. 힌디어는 Nirmala UI, 일본어는 Yu Gothic 등의 경로를 확인했고 대표 화면을 직접 검토했다.

Windows Chrome에서 사용하는 폰트 경로의 증거다. Android/iOS의 실제 글리프와 폰트 렌더링은 별도 확인 대상이다.

## 모션·사운드 검사

나머지 **68항목**은 음소거, 예약된 소리 정리, 화면 숨김, 닫힌 컨텍스트 복구, 오디오 미지원 시 입력, 전체/축소/OS 축소 모션, 설정 변경 중 효과 정리, 게임오버 연출 취소와 새 판 보호 등을 검사한다.

21종 효과음(20개 SND 메서드와 chime)을 기본/강화 설정 각각 OfflineAudioContext 48kHz·8초로 렌더링했다. 두 중첩 시험을 포함해 **44렌더**에서 피크·RMS·잔음·비정상 숫자를 측정했다. 소리 발생과 정리는 실제 AudioContext에서도 확인했다.

| 고의적인 12묶음 동시 중첩 시험 | 수정 전 피크 | 수정 후 피크 |
|---|---:|---:|
| 기본 효과 | 6.544 | 0.894 |
| 강화 효과 | 1.073 | 0.894 |

12묶음은 thunk+impact+chime을 동시에 실행한 스트레스 조건이다. 고정 난수로 잡음을 생성해 전후를 비교했다. 모든 단일 효과와 이 스트레스 조건은 피크 1 이내, 마지막 0.1초 잔음 0, NaN/Infinity 0건이다. 실제 스피커의 음질이나 플레이 중 중첩 빈도는 이 수치와 별도로 확인해야 한다.

음소거·화면 숨김·정리 후 연결된 예약 소스가 0개인지 확인한다. 중단한 소스의 ended 이벤트가 지연될 수 있어 연결 해제도 함께 측정한다.
