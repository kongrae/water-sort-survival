# 다국어 구현·검증 보고

작성일: 2026-10-09. 이전 확장 무한모드·UI 개선·현재/다음 조각 배치·보트리스 명칭을 유지하면서 국제화했다.

## 변경

- 기존 선택한 7개 언어에 힌디어와 인도네시아어를 추가했다. 선정 근거와 자료의 한계는 [국가 조사](MARKETS.md)에 기록했다.
- 343개 메시지를 한국어 원문과 8개 번역으로 관리한다. 화면, 설정, 실험 규칙, 도움말, 결과·공유, 테마·색 이름, 클라우드 안내, 접근성 레이블을 포함한다.
- 브라우저 선호 언어를 순서대로 확인하고 미지원 언어는 영어로 표시한다. 간체/번체는 명시한 문자 체계를 지역보다 우선한다. 설정에서 수동 변경·자동 선택을 지원하고 기기에 저장한다.
- 언어 변경은 게임을 재시작하지 않는다. 현재 상태·되돌리기·미적용 실험 규칙·기존 저장은 유지한다. 새 저장 키는 언어 선택용 wsurv.locale 하나다.
- 비한국어는 해당 문자권을 지원하는 시스템 글꼴을 사용한다. 작은 화면의 긴 안내와 인도네시아어 빈칸 표기를 다듬었다. 작은 화면의 비한국어 일일 도전 배지에는 짧은 모드명을 표시하고 날짜는 전체 접근성 레이블·제목에 유지한다.
- 빌드 시 번역 표를 단일 HTML에 포함한다. 추가 런타임 라이브러리나 번역 네트워크 요청은 없다. 빈 번역·중복 키·누락한 동적 문구·자리표시자 불일치를 빌드에서 거부한다.

## 공개 배포 확인

기존 deploy-pages.ps1로 main 소스와 gh-pages 배포 파일을 게시한다. 이후 node scripts/verify-pages.js가 공개 HTML과 로컬 빌드의 SHA-256, version.json의 소스 커밋, 번역 런타임과 엔진을 대조한다. 실행 결과는 outputs/i18n/public.json, 브라우저 캡처는 outputs/i18n에 남긴다.
