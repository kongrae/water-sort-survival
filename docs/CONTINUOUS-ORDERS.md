# 연속 주문 66–68판

납품 스테이지의 `새 연속 주문 · 66~68판` 버튼에서 선택합니다. 버튼은 목표 미리보기만 열며, 기존 진행을 즉시 교체하지 않습니다. 다른 판을 시작하면 진행 중인 한 판이 교체된다는 기존 안내를 유지합니다.

66·67·68판은 같은 보드에서 세 주문을 이어서 처리합니다. 병·조각·홀드·공급 위치는 다음 주문에 이어집니다. 기존 1~3칸 직접 제출, 같은 색 4칸 자동 납품, 주문에 없는 색 4칸 비움, 붓기·홀드·뒤집기·되돌리기를 사용합니다. 완성한 4칸은 현재 주문에만 반영됩니다. 다음 주문량은 플레이 화면에서 확인할 수 있습니다.

연속 주문은 별점 없는 연습판입니다. 세 주문 전체의 누적 플레이 시간과 클리어·진행 중 한 판을 저장하고 별점·최고 시간은 기록하지 않습니다. 시작/계속하기 이후 생각하는 시간도 포함합니다. 안내·일시정지·앱 이탈 중에는 멈추고, 이어하기는 멈춘 상태에서 열립니다. 주문 전환·되돌리기는 시간을 초기화하거나 환급하지 않습니다.

기존 65판의 내용·번호·별점 기준·기록 계약은 그대로입니다. 연속 주문은 원래 저장 키 `wsurv.delivery.v1`와 스키마 2를 사용합니다. 등록된 3·12·60·63·65판 저장은 기존 호환성 로더로 읽으며 첫 성공 쓰기 전에 `wsurv.delivery.upgrade.<old-pack-hash>.v1`에 기존 원문을 보존합니다. 오래된 탭·충돌·할당량 오류·작성 권한 없음에서는 기존 데이터를 덮어쓰지 않습니다. 연속 주문만 오래된 실행 중 체크포인트에 오프라인 벽시계 시간을 더하지 않습니다. 기존 별점판의 시간 정책은 유지합니다.

저장은 같은 브라우저·프로필·주소에만 적용되며 Firebase와 동기화하지 않습니다. 연구판의 다른 주소·저장 키에 있는 진행은 공개 게임으로 자동 이전하지 않습니다. OS 강제 종료가 마지막 저장 이벤트를 생략하면 마지막 체크포인트 이후의 시간은 보장할 수 없습니다.

구버전 앱은 확장된 68판 저장을 읽지 못하므로, 롤백할 때도 새 저장을 읽는 로더와 68판 내용은 유지해야 합니다. 백업 원문으로 조용히 되돌리면 이후 진행이 소실되므로 자동 복원하지 않습니다.

PC에서 기존 65판 경로, 저장 호환성, 새 3판, 9개 언어, 작은 화면을 검사했습니다. 실제 iPhone Safari의 회전·앱 전환·화면 잠금 확인은 보류 상태입니다. 이 배포는 실기기 합격이나 정식 출시 적합성을 뜻하지 않습니다.
