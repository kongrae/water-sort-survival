## 4. 후반 조각 곡선

새 표준 무한모드의 첫 후보는 다음과 같다.

| 점수 기준 | 생성 대상 조각 중 3칸 확률 | 3칸 조각 중 단색 AAA 비율 | 3칸 조각 중 2색 혼합 비율 |
|---|---:|---:|---:|
| 4,500 | 5% | 50% | 50% |
| 10,000 | 8% | 30% | 70% |
| 15,000 | 10% | 20% | 80% |
| 25,000 | 12% | 10% | 90% |

1. 각 기준 사이에서 두 확률을 **선형 보간**한다. 정수 반올림으로 계단식 난도를 만들지 않는다. 마지막 기준 이후는 마지막 값으로 고정한다.
2. 적용 조건 이전에는 현재 5%·50% 정책을 그대로 사용한다. 특히 8병에 도달했지만 아직 9색이 활성화되지 않은 구간을 바꾸지 않는다.
3. 확률은 조각을 새로 생성하는 순간의 실제 `S.score`와 활성 상태를 기준으로 계산한다. 턴 수·예상 점수·향후 성장 목표를 사용하지 않는다.
4. 성장 중 새로운 색을 소개하는 우선 조각은 현재 정책대로 생성한다. 이 조각은 일반 3칸 추첨 대상과 확률 통계의 분모에서 제외한다.
5. 단색은 AAA, 혼합은 AAB·ABA·BAA만 허용한다. A와 B는 서로 다르며 색·형태 선택의 균등성은 기존 정책을 유지한다.
6. 3칸 추첨에 걸리지 않은 조각은 기존 일반 생성 경로로 보낸다. 최대 확장 후 그 경로의 1칸·2칸 비율은 10%·90%다. 예를 들어 3칸 확률 12%일 때 전체 비율은 1칸 8.8%, 2칸 79.2%, 3칸 12%다.
7. 표의 단색 비율은 **3칸 안에서의 조건부 비율**이다. 전체 조각 중 AAA 비율로 잘못 해석하지 않는다.
8. 현재 조각·확정된 다음 조각 큐·보관 중인 홀드 조각은 점수 경계를 넘어도 바꾸지 않는다. 큐에 이미 공개된 조각이 남아 있어 체감 변화가 늦게 나타나는 것은 정상이다.

25,000점 상한은 이번 비교를 위한 첫 종료점이다. 그 이후에도 난도가 영원히 증가한다고 설명하지 마라. 먼저 이 곡선으로 고득점 압박이 실제 개선되는지 확인한다.

7. **탐색 격리:** 봇·솔버의 복제 상태를 진행해도 원본 플레이어의 규칙·큐·난수가 변하지 않는지 확인한다.
8. **기존 조작:** 홀드 후 패배 재판정, 뒤집힌 조각, 붓기 중 입력, 실패 입력, 종료 상태가 기존 계약대로 동작하는지 확인한다.

기존 대표 실행 경로는 다음과 같다. 실제 인자·의존성은 파일을 확인하고 사용한다. 새 압박 검증·비교 도구는 이번에 별도로 추가한다.

```text
node build-pages.js
node test-v2.js
node research/hold-triple/engine-test.js
node research/expansion/engine-test.js
node uitest/hold-triple.js
node uitest/compact-hud.js
node uitest/fx-polish.js
node uitest/i18n.js
node uitest/mobile-viewport.js
node uitest/presentation-audit.js --out=outputs/late-pressure/presentation --data=research/late-pressure/out/presentation
node uitest/real.js
node research/feel/perf.js
```

테스트가 기존 보고서를 덮어쓰는지 먼저 확인하고 별도 출력 경로를 사용한다. 브라우저 작업은 공유 서버·출력 충돌이 없도록 실행한다. 과거 시각 개선의 엔진 해시 동일성 검증기는 그 작업의 증거이므로 삭제하거나 기준을 느슨하게 만들지 않는다. 이번 엔진 변경에는 별도 행동 동치 검증을 사용한다.

## 8. 제한된 밸런스 비교

`research/late-pressure/`에 기존 봇·비교 구조를 재사용한 도구와 보고서를 만든다. 플레이어용 실험 모드는 추가하지 않는다.

| 비교 조건 | 3칸 확률 | 3칸 중 단색 비율 |
|---|---|---|
| 기준선 | 현재 5% 고정 | 현재 50% 고정 |
| 확률 증가만 | 후보 점수 곡선 | 50% 고정 |
| 전체 후보 | 후보 점수 곡선 | 후보 단색 감소 곡선 |

- 세 조건의 홀드·성장·점수·일반 조각 정책과 봇 판단 정책은 동일하게 유지한다.
- 새 고정 시드 접두사 `late-pressure-20261010-`로 조건당 40개 시드를 사용한다. 기존 1회 붓기 탐색·2회 붓기 탐색 두 정책을 각각 실행해 총 240판을 비교한다. 판당 성공 배치 제한은 우선 1,500회로 맞춘다.
- 소스·엔진·봇 해시, 규칙 전체와 서명, 시드, 탐색 조건, 종료 이유, 실제 표본 수를 기록한다. 과거 도구의 오래된 기준 커밋을 그대로 복사하지 않는다.
- 10,000·15,000·25,000점 도달 수, 최초 도달 이후 생존 배치 수, 점수 구간별 빈 공간·배치 가능한 병 수·홀드 사용·단색/혼합 생성 비율을 비교한다.
- 새 규칙이 발동하기 전 행동 동치는 별도로 검증한다. 전체 판 평균만으로 후반 개선을 판단하지 않는다.
- 배치 제한에 도달한 판은 종료 기록이 아니라 **관측 중단된 하한**으로 표시한다. 제한 도달 판이 많으면 실제 중앙 생존 길이를 계산했다고 보고하지 않는다.
- 10,000점 도달 표본이 적다면 0을 섞어 후반 평균을 만들지 않는다. 사전에 정한 기준선 시드의 실제 유효 체크포인트를 모두 사용한 추가 비교를 할 수 있다. 현재·미리보기·홀드 조각은 동일하게 두고 이후 생성 정책만 바꾼다. 이 결과는 처음부터 시작한 비교와 분리하고 조건부 비교임을 표시한다.
- 같은 시드라도 홀드·점수·생성 횟수가 달라지면 이후 조각열이 달라질 수 있다. 단색 비율 하나의 인과 효과라고 단정하지 않는다.
- 봇 탐색 한계와 실제 합법 수 없음에 따른 종료를 구분한다. 봇 깊이를 초보·숙련자라고 부르거나 배치 수를 사람의 플레이 시간으로 환산하지 않는다.

바람직한 결과는 초반 계약을 유지하면서 10,000점 이후 빈 공간과 생존에 일관된 압박이 늘어나는 것이다. 전체 후보가 오히려 더 쉬워지거나 대부분 제한까지 버티면 개선 성공으로 보고하지 않는다.

필요하면 **추가 조정은 1회만** 수행한다. 3칸 상한 15% 이하·단색 하한 10% 이상 안에서 표를 조정하고 같은 시드로 재비교한다. 새 기능으로 범위를 넓히거나 끝없는 매개변수 탐색을 하지 않는다. 최종 수치와 선택 근거를 기록하고, 후반 압박이 개선되지 않으면 검증되지 않은 점을 명확히 보고한다.

## 9. 브라우저·성능 확인

- 데스크톱·모바일 대표 뷰포트에서 6/7/8병, 2/3칸 조각, 홀드, 성장 전후와 후반 이정표를 직접 확인한다. 강제로 구성한 상태는 실제 처음부터 플레이한 증거와 구분한다.
- 마우스·터치, 기존 붓기/탭 조작, 상하 조각 영역, 홀드와 뒤집기 입력을 확인한다. 20/50/80ms 간격의 연속 입력에서도 큐·효과·입력이 서로 꼬이지 않는지 확인한다.
- 9개 언어의 긴 문구, 안전 영역, 병 높이, HUD 줄 수, 세로 스크롤 방지와 기존 테마를 확인한다. 마지막 이정표의 긴 번역 때문에 병이 작아지면 문구와 기존 표시 방식을 조정한다.
- 최근 병 재질과 붓기·착지·클리어·성장 효과를 대표 장면에서 재생한다. 점수 안내를 갱신할 때 불필요한 전체 재배치나 효과 재생이 생기지 않게 한다.
- 동일 환경·동일 절차로 수정 전후 성능을 비교한다. 초기 실행과 충분히 준비된 반복 실행을 분리하고 표본·변동 폭을 보고한다. 순수 확률 계산 때문에 매 프레임 탐색·레이아웃 측정을 추가하지 않는다.
- 과거 `research/feel` 전체 검증의 알려진 실패는 현재 수정 전후 결과를 비교해 기존 문제와 새 회귀를 구분한다. 테스트나 허용 오차를 삭제해서 성공으로 만들지 않는다.
- 자동 브라우저 결과는 실제 휴대폰·사람의 재미 검증과 구분한다. 확인하지 않은 FPS·사운드 체감·물리 기기 성능을 보장하지 않는다.
