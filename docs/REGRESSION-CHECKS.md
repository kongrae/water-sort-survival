# 배포 전 회귀검사

프로젝트 루트에서 다음 명령을 실행합니다. Node.js 기본 모듈만 사용하며 추가 설치는 필요하지 않습니다.

```powershell
node scripts/check-game.js
```

다른 폴더에서도 절대 경로로 실행할 수 있습니다.

```powershell
node C:/workspace/water-sort-survival/scripts/check-game.js
```

현재 엔진 검사, 이전 규칙 검사, v2 수용 검사, 납품 회귀검사를 차례로 실행합니다. 자식 검사의 실패·비정상 종료·120초 제한 초과를 실패로 보고하며, 나머지 검사의 결과도 확인한 뒤 하나라도 실패하면 종료 코드 1을 반환합니다. 테스트 실패를 출력만 하고 성공 종료하던 `engine-test.js`와 `engine-test-v1.js`의 동작도 수정했습니다.

검사는 소스와 고정 fixture를 읽으며 메모리 저장소만 사용합니다. 빌드·임베딩·배포를 실행하거나 게임 파일, 연구 결과, 실제 브라우저 저장을 쓰지 않습니다. 실제 UI를 새로 조작하는 검사와 실기기·초보자 플레이 평가는 포함하지 않습니다.

## 납품 검사 범위

`node tests/delivery-regression.js`로 납품 검사만 실행할 수도 있습니다.

- 임베딩된 엔진·UI·CSS·저장 모듈·팩·manifest와 원본 모듈의 일치, 모든 script의 구문 검사
- 기존 번역 검사기를 재사용한 납품·경로 모드 키 누락 검사, 9개 언어의 열·자리표시자·임베딩 일치
- 68판 전체와 C의 대체 경로 2개: 70경로·535동작의 상태 기준값, 저장·새 로더 복원·이어하기·완주
- 주문 전환을 되돌린 10개 상태의 복원과 누적 시간 유지
- 과거 공개 3·12·60·63·65판의 저장 로드, 읽기 전용 로드, 첫 쓰기 전 원문 백업, 기존 활성 판의 후속 완주
- 기존 65클리어·51개 별점/최고 시간에서 연속 주문 3판을 완료한 뒤 기록 보존
- 연속 주문의 소수 누적 시간·일시정지·오래된 실행 중 체크포인트, 기존 별점판/연습판과 서로 다른 시간 정책
- 백업 실패·본 저장 실패와 재시도, 백업 충돌·작성 권한 상실·다른 탭의 변경·미등록 팩·잘못된 동작 이력에서 원문 보호
- 무한·데일리·기존 스테이지·재화·복구 키 보존

## 고정 fixture의 출처와 유지

`tests/fixtures/delivery-routes.json`은 T93 소스 `85ec55f5c92673d93fe2bfa61a05e4d9c1fd1e59`에서 통과한 경로를 고정했습니다. 기존 60판은 T54, 추가 3판은 T61, 64·65판은 T85, 연속 주문 5경로는 T91/T93의 검증 자료가 출처입니다. 상태 해시는 객체 키를 정렬하고 배열 순서는 유지해 계산한 SHA-256입니다. 추출의 색상 인수도 경로에 고정해 저장 이력을 명시합니다.

`tests/fixtures/delivery-legacy-saves.json`은 공개 65판 소스 `bdecd64f1982c7b6f1b110ede3faab4bfa04e23a`의 실제 이전 저장 모듈과 엔진으로 만든 합성 저장입니다. 3·12·60·63판은 해당 공개 팩 접두 자료에서 만들었고, 65판은 T93에서 보존한 51개 기록/65클리어/진행 중 65판 fixture의 원문을 복사했습니다. 사용자의 개인 브라우저 저장이 아닙니다. 실행 시 연구 폴더나 과거 엔진은 필요하지 않습니다.

새 판을 추가하면 검증한 경로와 상태 기준값을 추가하고 fixture의 팩 해시를 갱신해야 합니다. 커버되지 않은 판, 임베딩 누락, 기존 공개 판 변경은 실패합니다. 실패를 없애려고 기존 기준값·구버전 원문을 일괄 재생성하거나 공개 팩 레지스트리를 삭제하지 않습니다. 먼저 변경이 의도한 규칙/호환성 계약에 맞는지 확인해야 합니다.

브라우저 UI·공개 CDN 일치·실제 iPhone Safari의 회전/앱 전환/잠금은 별도 검증입니다. 이 명령의 통과를 실기기 합격이나 재미·출시 준비 완료로 해석하지 않습니다.

## 2026-10-22 실행 결과

프로젝트 밖 `C:/`에서 절대 경로 명령으로 실행해 4개 검사 묶음 모두 실패 0건으로 완료했습니다. v2 수용 검사는 1,070건이며 납품 검사는 위 70경로·535동작·535복원·10회 주문 경계 되돌리기를 통과했습니다.

파일에 쓰지 않은 변형 코드로 연속 주문의 이탈 시간 잘못 부과, 원문 백업 생략, 되돌리기의 시간 환급을 각각 주입했고 해당 시간·백업 assertion에서 모두 실패했습니다. 이전 규칙 검사에 잘못된 점수 기대값을 주입한 경우도 종료 코드 1을 확인했습니다. 실행기에는 자식 실패·시그널 종료·시간 제한 오류를 모의 주입해 전체 실패 반환과 나머지 검사 실행을 확인했습니다.

게임 HTML·납품 모듈·번역 파일은 변경하지 않았습니다. 무관한 기존 변경 7개와 과거 T87~T93 manifest의 310개 파일 해시도 유지했습니다. 이번 작업은 로컬 검사 도구 정비이며 GitHub Pages 배포는 수행하지 않았습니다.
