# 보트리스: 물병 정렬 퍼즐

2026-10-09 사용자 확정 명칭과 한국어 스토어 등록용 문구.

## 스토어 제목

보트리스: 물병 정렬 퍼즐

## 짧은 소개

물 정렬과 콤보의 만남! 병을 비우고 판을 넓히며 최고 기록에 도전하는 무한 워터 소트 퍼즐.

## 홍보 문구

한 병 비우고, 한 번 더! 끝없이 이어지는 컬러 콤보.

## 적용 위치

- 게임 화면: `보트리스` 아래에 `물병 정렬 퍼즐`을 표시한다.
- 브라우저 제목과 오늘의 도전 공유 결과: 전체 이름을 사용한다.
- 웹 설명 메타데이터: 짧은 소개를 사용한다.
- 스토어 등록 시: 위 제목·소개·홍보 문구를 사용한다. 현재 외부 스토어에는 등록하지 않았다.

표시 이름 변경은 기존 `wsurv.*` 저장 키, 기록 서명, Firebase 프로젝트 식별자, 저장 데이터 구조와 게임 규칙을 변경하지 않는다.
